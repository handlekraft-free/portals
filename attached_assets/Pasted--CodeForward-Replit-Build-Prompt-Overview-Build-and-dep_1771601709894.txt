# CodeForward — Replit Build Prompt

## Overview

Build and deploy a single-page website for **CodeForward**, an early-stage 501(c)(3) nonprofit initiative that provides free bespoke software and web design to community organizations while training underserved candidates in AI-assisted software development. This site will be shared with a small group of potential foundational donors, so it should feel professional but honest about being early-stage — this is a vision being brought to life, not a mature organization pretending to be bigger than it is.

The site should also host a downloadable PDF version of the full organizational proposal.

-----

## Tech Stack

- **Single HTML file** (index.html) with embedded CSS and JS — no frameworks, no build step
- Fonts: Google Fonts — `DM Serif Display` (headings) and `Outfit` (body)
- Fully responsive (mobile, tablet, desktop)
- Host directly on Replit with the static file server
- Include a `/proposal.pdf` file in the project (I will upload the PDF separately — create a placeholder reference for now)

-----

## Design Direction

**Aesthetic:** Refined, confident, civic-tech. Dark navy (#0B1D3A) hero with teal (#0EA5E9) accents. Cream (#FAF7F2) for light sections, white for alternating sections. This is NOT a startup landing page — it’s a mission-driven organization. Think editorial, trustworthy, warm but serious.

**Typography:** DM Serif Display for all headings (with slight negative letter-spacing). Outfit (weight 300–600) for body text. Large section titles, generous line height, plenty of whitespace.

**Tone of copy:** Direct, human, zero jargon. Speak to donors as peers. Acknowledge this is early-stage. Emphasize the founder’s background (retiring SDVOSB software entrepreneur), the dual-impact model, and the timing opportunity with AI-assisted development tools.

## Interactions & Polish

- **Scroll animations:** Elements with class `.fade-up` start invisible and translate up 30px, becoming visible when they enter the viewport (IntersectionObserver, threshold 0.15)
- **Hero gradient animation:** Slow 20s drift animation on the radial gradient background
- **Card hovers:** Subtle translateY(-4px) lift with soft box-shadow
- **Candidate tags:** On hover, invert to navy background with white text
- **Smooth scroll:** `html { scroll-behavior: smooth; }`
- **Mobile hamburger:** Toggles nav links open/closed

## Important Notes for the Build

1. **This is early-stage.** The badge in the hero says “Early-Stage 501(c)(3) Nonprofit Initiative.” The proposal section frames this as a founding-stage organization seeking foundational support. Don’t overclaim.
1. **Proposal PDF:** Create a placeholder link to `/proposal.pdf`. I will upload the actual PDF file to the Replit project. If you want, also create a simple route or just serve it as a static file.
1. **No backend needed.** This is a static site. The mailto links are intentional placeholders until we build contact forms.
1. **Performance:** Everything in one HTML file. No external JS libraries. CSS animations only (no animation libraries). Google Fonts are the only external dependency.
1. **Accessibility:** Semantic HTML, proper heading hierarchy, alt text concepts for any decorative elements, sufficient color contrast, keyboard-navigable.
1. **Deploy:** Should work immediately with Replit’s static hosting. Just serve index.html from the root.
